EXPERIMENT NO: 3.2
CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION


1. AIM

To create a three-dimensional (3D) solid model of the given component from its orthographic projections using
Autodesk Fusion 360, and to prepare the corresponding engineering drawing. 


2. REQUIREMENTS

Software Required: Autodesk Fusion 360. System Requirements:

1. Operating System: Windows 10.
2. RAM: 16 GB.
3. Graphics: Integrated graphics with 1 GB or more graphics memory recommended.
4. Internet download speed: 2.5 Mbps or faster.
5. Internet upload speed: 500 Kbps or faster.



3. INTRODUCTION

Orthographic projection is a technical drawing method used to represent a three-dimensional component through
two-dimensional views. The front, top and side views show the shape, dimensions and relative positions of the
features of the component. By studying these views, the complete shape of the object can be understood and
reproduced in a 3D modelling application. Autodesk Fusion 360 is a computer-aided design (CAD) software used for creating sketches, solid models and
engineering drawings. In this experiment, the given orthographic drawing is used as a reference to construct the
component. Sketching tools are used to create the required profiles, dimensions are applied to control their size
and position, and solid modelling commands such as Extrude and Cut are used to form the final component. 




4. TOOLS AND COMMANDS USED

Create Sketch: Starts a new two-dimensional sketch on a selected plane or flat face. 

Line and Rectangle: Used to draw straight edges and rectangular portions of the component. 

Circle and Arc: Used to create circular holes, curved outlines and rounded portions. 

Sketch Dimension: Applies the required lengths, diameters and positions to sketch geometry. 

Trim: Removes unwanted portions of sketch lines or curves. 

Mirror: Creates a reflected copy of selected sketch geometry where symmetry is required. 

Inspect: Measures distances and checks dimensions in the design. 

Finish Sketch: Completes the active sketch and returns to the solid modelling workspace. 

Extrude: Adds depth to a closed sketch profile to create a solid feature. 

Cut: Removes material from an existing solid to form holes, slots or recesses. 

Drawing Workspace: Creates the technical drawing with orthographic and isometric views.


5. PROCEDURE

Step 1: Open Autodesk Fusion 360

Launch Autodesk Fusion 360 and create a new design file. Check that the Design workspace is active. Save the
file with a suitable experiment name. 

Step 2: Start a New Sketch

Select the Sketch option from the toolbar and choose Create Sketch. This opens the sketch environment, where
the two-dimensional outline of the component can be created. 

Step 3: Select the Sketch Plane

Choose a suitable reference plane, such as the Front or Top plane, by referring to the orientation of the given
orthographic views. The selected plane will be used to draw the initial profile. 

Step 4: Draw the Main Base Profile

Use Line, Rectangle, Circle and Arc tools to draw the main base outline. Refer to the orthographic drawing to
create the elongated base and the rounded end portions. Use the dimensions shown in the drawing to define the
overall length and the positions of the features. 

Step 5: Create the Central Curved Profile

Draw the central raised curved portion using the Arc and Line tools. The front view indicates the curved upper
profile, while the top and side views provide information about its width and depth. Connect the sketch entities
properly to form the required closed profile. 

Step 6: Draw the Circular Features

Use the Circle tool to create the circular openings at the two end portions and the required circular feature on the
central body. Locate the circles according to the centre positions and diameter dimensions provided in the
drawing. 

Step 7: Modify and Complete the Sketch

Use Trim, Extend, Mirror and other sketch modification tools wherever necessary. Remove unwanted sketch
portions and ensure that the profiles used for solid modelling are closed and properly connected. 

Step 8: Apply Dimensions

Use Sketch Dimension to specify the lengths, radii, diameters and distances between important features. Enter the
values shown in the supplied orthographic drawing. This helps maintain the correct proportions and positions of
the component. 

Step 9: Inspect the Sketch

Use the Inspect tools to measure important distances and verify the dimensions of the sketch. Compare the sketch
with the given front, top and side views to check that the geometry represents the drawing correctly. 

Step 10: Finish the Sketch

After completing the outline and applying the required dimensions, select Finish Sketch. The completed two- dimensional profile is now ready for solid modelling operations. 

Step 11: Create the Base Solid Using Extrude

Select the required closed base profile and choose Extrude from the Solid workspace. Enter the depth specified by
the drawing and confirm the operation. This creates the main base portion of the component.

Step 12: Create the Raised Curved Body

Select the appropriate face or reference plane and create a new sketch for the central raised portion. Draw the
curved profile according to the orthographic views, finish the sketch and use Extrude to add the required solid
material. Choose the appropriate operation so that the new feature joins the base body. 

Step 13: Form the Openings and Holes

Create sketches for the circular openings and other internal features on the suitable faces. Use the Cut or Extrude
Cut operation to remove material and form the holes. Apply the dimensions and locations shown in the drawing. 

Step 14: Complete and Review the 3D Model

Repeat the sketching and modelling operations for any remaining details. Use the Orbit and ViewCube controls to
inspect the completed component from different directions. Confirm that the curved central body, base portions
and openings match the given drawing. 

Step 15: Prepare the Engineering Drawing

After completing the 3D model, select the Drawing workspace and create a drawing from the design. Choose the
required sheet size and set the drawing standard to ISO.

Step 16: Place Views and Dimensions

Place the front, top and side views on the drawing sheet. Add an isometric view to show the overall shape of the
component. Include the required dimensions, centre lines and hidden lines, and arrange the views clearly on the
sheet. 

Step 17: Save the Design and Drawing

Review the final model and drawing sheet. Save the Fusion 360 design and the completed technical drawing for
submission.

The input for this experiment is the given orthographic projection drawing of the component. The front, top and

7. OUTPUT

The 3D solid model of the given component was created using Autodesk Fusion 360. The completed model
